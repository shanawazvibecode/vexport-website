Team Member Collaboration Guide

How any non-technical team member can add or edit website information.

How to Add a New Product
  1. Click "Add New Product" button on the top right.
  2. Fill in Product Name (e.g. Kashmiri Saffron or White Sesame Seeds).
  3. Select Category (Spices, Pulses, or Fresh Produce).
  4. Enter MOQ (e.g. 1 FCL 20ft Container) and HS Code.
  5. Add image path (e.g. assets/images/new-product.jpg).
  6. Click "Save Product". It will appear immediately in the catalog!
How to Publish to the Live Website
  1. After editing products, click "GitHub Sync" at the top.
  2. If you connected your GitHub account or Personal Access Token, click "Push to Live".
  3. Alternatively, click "Export / Download Data" and save the file into assets/js/product-data.js.
  4. Once connected to Vercel, any GitHub push goes live worldwide in under 15 seconds!
